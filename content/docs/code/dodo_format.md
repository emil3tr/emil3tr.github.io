title: "Doubledot Format"
weight: 5
---

The Doubledot format is a simple text description format that provides an alternative to Markdown + SomethingElse
when writing structured and styled text (like websites).

The [project](https://github.com/emil3tr/dodo-format) currently contains a somewhat efficient C++ parser and some examples. I might finish it in the future
when I have time.
