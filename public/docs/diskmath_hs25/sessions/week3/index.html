          Proving Proof Patterns with Propositional Logic

          Okay, we we already know a lot of proof patterns. But what if we want to create our own one and show that it is actually correct? Or what if someone gives us a proof pattern they came up with and we want to show them that it does not work?

          We can do both of those things using propositional logic! I will explain the idea first and then give examples for both proving and disproving a proof pattern.

          When you are asked to evaluate a proof pattern, it will always be of the following form: It states what statement SSS it wants to prove and then gives some other statements. Then it claims if we prove those other statements, we have actually proven the statement SSS. For example, a proposed proof pattern might look like this:

          We want to prove the statement SSS, we first prove another statement TTT. Then we show that T  ⟹  ST \implies ST⟹S

          This proof pattern consists of two parts (which should prove SSS):

          1. We prove TTT
          2. We prove T  ⟹  ST \implies ST⟹S

          You might also see proof patterns with more steps and parts. Don’t get confused! The first step is always to find out what statements the pattern consists of.

          Great, but how do we work with the proof pattern now? Here is where the logic part comes in. We can actually rewrite the pattern using propositional logic. To do this, we take each of the statements, convert them to propositional logic and then combine them with ∧\land∧. To avoid confusion, we use the letters A,B,C,…A, B, C, \dotsA,B,C,… in our formulas and let their truth values correspond to the truth of the statements. For our example proof pattern this would look like this:

          We choose the symbol AAA and BBB, which correspond to the statements SSS and TTT and their truth values respectively. Now we rewrite the statements in propositional logic:

          1. “We prove TTT” becomes BBB
          2. “We prove T  ⟹  ST \implies ST⟹S” becomes B→AB \rightarrow AB→A

          Combining those we get: F=B∧(B→A)F = B \land (B \rightarrow A)F=B∧(B→A)

          Okay, we tranformed our statements to a formula FFF. But how do we reason about the correctness of the proof pattern? There is actually a very simple rule:

          The proof pattern is correct exactly if:

          F⊨A F \vDash A F⊨A

          Where FFF is the formula we get from the proof pattern and AAA is the logical variable corresponding to the statement we want to prove. This means we can disprove a proof pattern by showing:

          F⊭A F \nvDash A F⊭A

          Why does this work? We want to show that our statement SSS is true if we proved all the other statements. Our formula FFF evaluating to true represents the fact that all the statements are true (since we “linked” each propositional variable to a statement and combined them with ∧\land∧). If F⊨AF \vDash AF⊨A then this means that if all our statements are actually true (FFF is true), then SSS must also be true (AAA is true). If the logic consequence does not hold, then there must exist some truth assignment where FFF gives true but AAA is set to false. This means that SSS can be false even if all our statements are true, which means the pattern is not valid.

          If the statement you want to show is not simply one statement SSS, but for example S  ⟹  TS \implies TS⟹T, then you need to transform that to propositional logic too and show the consequence. This should look like:

          F⊨(A→B) F \vDash (A \rightarrow B) F⊨(A→B)

          So let’s finish our small example. We show that F⊨AF \vDash AF⊨A:

          F=B∧(B→A)≡B∧(¬B∨A)≡(B∧¬B)∨(B∧A)≡⊥∨(B∧A)≡B∧A⊨A \begin{align*} F & = B \land (B \rightarrow A) \\\\ & \equiv B \land (\lnot B \lor A) \\\\ & \equiv (B \land \lnot B) \lor (B \land A) \\\\ & \equiv \bot \lor (B \land A) \\\\ & \equiv B \land A \\\\ & \vDash A \end{align*} F​=B∧(B→A)≡B∧(¬B∨A)≡(B∧¬B)∨(B∧A)≡⊥∨(B∧A)≡B∧A⊨A​

          Step by Step

          Let’s go over the method step by step again before we do some examples:

          ### Extract the Statements See what statement $S$ should be proved by the pattern. Then find all the statements we use to prove that statement. (It does not need to be named $S$, we just assume that here for simplicity.)

          Transform the Statements to Prop. Logic

          Define propositional variables A,B,…A,B, \dotsA,B,… for the statements. Transform each statement individually and then combine them with ∧\land∧ to get a formula FFF.

          (Dis)prove the Cogical Consequence

          You can prove F⊨AF \vDash AF⊨A either by equivalence transformations or truth tables. You can disprove it by finding a truth assignment where FFF gives true but AAA is set to false.

          Example 1: Proving Correctness

          This is an exercise from 2020. We get the following proof pattern and want to show that it is correct:

          To prove SSS: Find statements UUU and TTT. Prove TTT, assuming SSS is false. Prove UUU, assuming SSS is false. Show that not both TTT and UUU are true.

          Step 1: We have three statements here:

          1. not S   ⟹  \implies⟹ T
          2. not S   ⟹  \implies⟹ U
          3. not both U and T are true

          Those statements should show S.

          Step 2: We use AAA for SSS, BBB for TTT and CCC for UUU. The formulas are:

          1. ¬A→B\lnot A \rightarrow B¬A→B
          2. ¬A→C\lnot A \rightarrow C¬A→C
          3. ¬(B∧C)\lnot (B \land C)¬(B∧C)

          Combining them we get:

          (¬A→B)∧(¬A→C)∧¬(B∧C) (\lnot A \rightarrow B) \land (\lnot A \rightarrow C) \land \lnot (B \land C) (¬A→B)∧(¬A→C)∧¬(B∧C)

          Step 3: To show that the proof pattern is correct we now need to show:

          (¬A→B)∧(¬A→C)∧¬(B∧C)⊨A (\lnot A \rightarrow B) \land (\lnot A \rightarrow C) \land \lnot (B \land C) \vDash A (¬A→B)∧(¬A→C)∧¬(B∧C)⊨A

          You can use a truth table to show that this holds. This shows that the proof pattern is indeed correct.

          Example 2: Disproving Correctness

          We want to show that the following proof pattern is incorrect:

          To prove S  ⟹  TS \implies TS⟹T we find a statement RRR and prove that R is true. Then we show that if RRR is true, SSS must be true. Finally, we show that at least one of RRR and TTT must be true.

          Step 1: We want to show S  ⟹  TS \implies TS⟹T using three statements:

          1. RRR is true
          2. R  ⟹  S R\implies SR⟹S
          3. RRR or TTT (or both) must be true

          Step 2: We use AAA for SSS, BBB for TTT and CCC for RRR. The formulas are:

          1. CCC
          2. C→AC \rightarrow AC→A
          3. C∨BC \lor BC∨B

          Combined we get:

          C∧(C→A)∧(C∨B) C \land (C \rightarrow A) \land (C \lor B) C∧(C→A)∧(C∨B)

          Step 3: We want to show that:

          C∧(C→A)∧(C∨B)⊭A→B C \land (C \rightarrow A) \land (C \lor B) \nvDash A \rightarrow B C∧(C→A)∧(C∨B)⊭A→B

          Note that we transformed the statement the pattern tries to prove into A→BA \rightarrow BA→B.

          For the truth assignment A=1,B=0,C=1A=1, B=0, C=1A=1,B=0,C=1 the left hand side evaluates to true, but the right hand side evaluates to false. This shows that the proof pattern is not valid.
